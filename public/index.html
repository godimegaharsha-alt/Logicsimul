7408 DIP-14
Quad 2-Input Positive-AND Gates

Contains four independent AND gates. Output Y is HIGH only when inputs A and B are both HIGH.

Pin 14: VCC (+5V) | Pin 7: GND
Gate 1: 1A(1), 1B(2) -> 1Y(3)
Gate 2: 2A(4), 2B(5) -> 2Y(6)
Gate 3: 3A(9), 3B(10) -> 3Y(8)
Gate 4: 4A(12), 4B(13) -> 4Y(11)
7432 DIP-14
Quad 2-Input Positive-OR Gates

Contains four independent OR gates. Output Y is HIGH if either input A or B is HIGH.

Pin 14: VCC (+5V) | Pin 7: GND
Gate 1: 1A(1), 1B(2) -> 1Y(3)
Gate 2: 2A(4), 2B(5) -> 2Y(6)
Gate 3: 3A(9), 3B(10) -> 3Y(8)
Gate 4: 4A(12), 4B(13) -> 4Y(11)
7404 DIP-14
Hex Inverter Gates

Contains six independent inverters (NOT gates). Inverts input logic level from 0 to 1 and vice versa.

Pin 14: VCC (+5V) | Pin 7: GND
Inv 1: 1A(1) -> 1Y(2)
Inv 2: 2A(3) -> 2Y(4)
Inv 3: 3A(5) -> 3Y(6)
Inv 4: 4A(9) -> 4Y(8)
Inv 5: 5A(11) -> 5Y(10)
Inv 6: 6A(13) -> 6Y(12)
7400 DIP-14
Quad 2-Input Positive-NAND Gates

Universal logic gate. Output Y is LOW only when both inputs A and B are HIGH.

Pin 14: VCC (+5V) | Pin 7: GND
Gate 1: 1A(1), 1B(2) -> 1Y(3)
Gate 2: 2A(4), 2B(5) -> 2Y(6)
Gate 3: 3A(9), 3B(10) -> 3Y(8)
Gate 4: 4A(12), 4B(13) -> 4Y(11)
7486 DIP-14
Quad 2-Input Exclusive-OR (XOR)

Outputs HIGH when inputs differ. Key component for half adders and parity checkers.

Pin 14: VCC (+5V) | Pin 7: GND
Gate 1: 1A(1), 1B(2) -> 1Y(3)
Gate 2: 2A(4), 2B(5) -> 2Y(6)
Gate 3: 3A(9), 3B(10) -> 3Y(8)
Gate 4: 4A(12), 4B(13) -> 4Y(11)
7447 DIP-16
BCD to 7-Segment Decoder / Driver

Decodes 4-bit Binary Coded Decimal (A, B, C, D) into active-low outputs for segments a through g.

Pin 16: VCC (+5V) | Pin 8: GND
Inputs: A(7), B(1), C(2), D(6)
Outputs: a(13), b(12), c(11), d(10), e(9), f(15), g(14)
